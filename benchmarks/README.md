# Performance baselines

Install the wheel under test, run `python /path/to/syntwine/benchmarks/bench.py`,
and keep its JSON report for comparison on the same Python, CPU, and power
configuration. `--case NAME` can be supplied multiple times to isolate a suspected
regression. `--rows` controls the large inputs and `--parts` the fan-out. Use
`--output .temp/name.json` to keep a local report. Each sample is wall-clock time
per invocation, in nanoseconds; fast workloads are batched to reduce clock
noise. There are no absolute timing assertions.

The startup case launches a new interpreter for each sample. The small assembly
case does not execute the graph; the small generation case reuses a graph but
creates a fresh session per invocation. Large format cases cover file read,
parse, and terminal serialization. Markdown covers the whole-document squish
barrier. Tokenizer warm-up separates vocabulary initialization from steady-state
counting. The fan-out case creates dependencies during evaluation; the callback
case isolates recurring C++ to Python transitions. Telemetry-on and -off use the
same prepared graph and differ only in the native trace and bounded memory sink.

## Initial Linux reference (2026-11-21)

Release CMake build with GCC 16.2, CPython 3.15.2, Linux x86-64 QEMU VM.
Median of five samples after one warm-up; fixtures are generated by the runner.
Using prebuilt Text Parts isolates assembly from Part creation.

| Parts | Python loop using `+=` | One `extend()` |
| ---: | ---: | ---: |
| 10,000 | 26.5 ms | 6.0 ms |
| 100,000 | 200.7 ms | 44.1 ms |

This spot check shows no quadratic growth in repeated append. Bulk `extend`
remains preferable when the Parts are already available as an iterable. On the
same VM the eight-Part telemetry case took about 13 µs without tracing and
434 µs with full operation spans and a memory sink. Compare future runs with
the same level, signals, and sink; the tracing cost depends on graph shape.

To reproduce the fan-out check, run the following with `N` equal to `10000` or
`100000`:

```console
python benchmarks/bench.py --case construct-fanout --case extend-fanout --parts N --rows 1 --repeat 5 --warmup 1
```
